# Security policy

## Supported versions

Only the latest published version of `@oaknational/oak-agent-skills` is supported. Fixes are released as a new version, not backported to earlier ones. A version with a known problem is marked with `npm deprecate`, because published versions can't be withdrawn.

| Version                   | Supported |
| ------------------------- | --------- |
| The latest version on npm | Yes       |
| Any earlier version       | No        |

## Reporting a vulnerability

To report a vulnerability, follow the instructions in Oak National Academy's [security.txt file](https://www.thenational.academy/.well-known/security.txt).

Please don't report vulnerabilities in a `skill-feedback` issue, a pull request or any other public channel.
