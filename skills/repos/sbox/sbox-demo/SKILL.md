# Sandbox demo

Use this skill only in the oak-agent-skills sandbox, to rehearse a workflow before other teams use it.

1. Read the repository's `AGENTS.md` for the commands it uses.
2. Say which workflow is being rehearsed, and what result would count as a pass.
3. After the run, list what passed, what failed, and anything that needed a manual step.
